1. PROJECT PURPOSE
The project is an AI-assisted data analytics application using React Native + Expo and FastAPI.
Users upload CSV, XLSX, or SQL dump files, inspect schemas and preview rows, ask natural-language questions, and receive Gemini-generated SQLite read-only results.
The project supports Expo web deployment on Vercel and Android APK builds.

2. TECH STACK
- Backend: Python 3.11+, FastAPI, Uvicorn, pandas, openpyxl, SQLite3, google-genai
- Frontend: React Native, Expo Router, React Native Web, TypeScript
- Backend hosting: Heroku Basic Dyno
- Web hosting: Vercel
- Android: EAS or local Expo APK build
- Temporary database: /tmp/{session_id}.db
- Upload limit: 20 MB
- Session TTL: 30 minutes

3. STRICT RESPONSIBILITY SEPARATION
- Frontend: UI, file picking, preview, chat, API calls, and session_id state only.
- API routes: HTTP validation and service delegation only.
- Ingestion: CSV/XLSX/SQL parsing and SQLite loading.
- Query: read-only SQL validation/execution and exact/keyword/related search.
- AI: Gemini prompts and result explanation only; never executes SQL.
- Lifecycle: UUID sessions, database paths, raw-file cleanup, and TTL cleanup.
- GEMINI_API_KEY remains backend-only.
- EXPO_PUBLIC_API_URL is the frontend public API setting.

4. BACKEND FILES
backend/app/core/config.py
- Loads GEMINI_API_KEY.
- Sets temp directory, 20 MB upload limit, 30-minute TTL, and CORS settings.

backend/app/core/errors.py
- Defines typed domain errors and clean JSON error payloads.
- Provides FastAPI error handlers.

backend/app/core/sqlite_safety.py
- Allows exactly one SELECT or WITH statement.
- Blocks DROP, DELETE, UPDATE, INSERT, ALTER, ATTACH, PRAGMA, VACUUM, and multi-statement SQL.
- Opens SQLite read-only and uses query_only plus an authorizer.

backend/app/services/lifecycle.py
- Generates UUID sessions.
- Resolves /tmp/{session_id}.db paths.
- Validates sessions and TTL.
- Deletes raw files and expired databases.
- Touches database activity on successful use.

backend/app/services/ingestion.py
- Parses CSV with pandas.
- Parses XLSX worksheets with pandas/openpyxl.
- Handles bounded SQLite-compatible SQL dump statements.
- Rejects empty/corrupt/unsupported/oversized/unusable files.
- Limits tables to 250 columns and 250,000 rows.
- Returns table names, columns, types, row counts, and previews.

backend/app/services/query.py
- execute_session_query validates and executes read-only SQL with 1,000-row output bound.
- search_session performs exact, prefix, contains, and keyword matching.
- Search is parameterized and case-insensitive.
- Supports optional column or table.column.
- Default searches all text/all columns in all session tables.
- Returns columns, rows, is_empty, and truncated.
- Does not call ai.py.

backend/app/services/ai.py
- Uses google-genai and GEMINI_API_KEY from config.
- generate_sql receives table schemas and the question only.
- Uses structured JSON response schema {"sql": "..."}.
- Rejects markdown fences, malformed JSON, invalid output, and empty SQL.
- explain_results receives question, executed SQL, column names, and bounded actual rows only.
- Produces concise grounded plain-English explanations.
- Never opens SQLite or executes SQL.

backend/app/api/routes.py
- GET /health.
- POST /upload.
- POST /ask.
- POST /search.
- /upload enforces extension and 20 MB limits, creates a session, ingests data, deletes the raw file in finally, and returns session_id/schema/preview.
- /ask retains schema-grounded Gemini SQL and read-only execution behavior.
- /search has no AI dependency.

backend/main.py
- Creates FastAPI app.
- Configures CORS from config.
- Registers typed error handlers.
- Runs startup and periodic TTL cleanup.
- Includes routes.

backend/requirements.txt
- fastapi, uvicorn, pandas, openpyxl, google-genai, python-multipart.

backend/runtime.txt
- python-3.11.10.

backend/Procfile
- uvicorn main:app --host 0.0.0.0 --port $PORT.

backend/tests/test_sql_safety.py
- Tests allowed SELECT/WITH and blocks forbidden SQL, comments, semicolons, and multi-statements.

backend/tests/test_ingestion.py
- Tests CSV, XLSX, SQL dump, empty/corrupt/unsupported/oversized files, and cleanup.

backend/tests/test_routes.py
- Tests health, upload, unsupported/empty upload, expired sessions, malformed AI JSON, and markdown AI JSON.

5. FRONTEND FILES
frontend/app/_layout.tsx
- Expo Router root Stack layout.

frontend/app/index.tsx
- Stores session_id, table schemas, messages, and search state.
- Wires upload, preview, search, and chat.
- Uses server search first and case-insensitive preview fallback if search fails.
- Resets chat/search when a new dataset is uploaded.

frontend/src/components/UploadPicker.tsx
- Uses expo-document-picker.
- Accepts CSV, XLSX, SQL.
- Enforces 20 MB UI limit.
- Shows loading/status/errors.

frontend/src/components/DataPreview.tsx
- Shows schemas, row counts, preview rows, and missing values as NULL.
- Provides horizontally scrollable tables.
- Provides search bar, search/clear controls, loading/error/empty/result states.

frontend/src/components/ChatPanel.tsx
- Shows user prompts, explanations, generated SQL, result tables, empty states, loading, and errors.

frontend/src/types/data.ts
- Defines upload, table, preview, ask, search, and chat types.

frontend/src/api/client.ts
- Uses EXPO_PUBLIC_API_URL only.
- uploadDataset sends multipart form data.
- Web converts URI into Blob/File.
- Native sends Expo URI/name/type object.
- askQuestion calls /ask.
- searchDataset calls /search.
- Handles JSON and network errors.

frontend/app.json
- Expo metadata, Router plugin, React Native Web static output, Android package.

frontend/package.json
- Expo dependencies and scripts for start, web, build:web, android, typecheck.

frontend/tsconfig.json
- Strict mode, noUncheckedIndexedAccess, module esnext, moduleResolution bundler.

frontend/vercel.json
- Static Expo web build to dist with SPA rewrite.

frontend/eas.json
- APK preview profile and app-bundle production profile.

6. DEPLOYMENT / RUN CONFIGURATION
Backend:
cd backend
.\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000

Backend tests:
cd backend
.\.venv\Scripts\python.exe -m pytest -q

Frontend:
cd frontend
npm.cmd run web -- --port 8081

Frontend typecheck:
cd frontend
npm.cmd run typecheck

Public frontend URL variable:
EXPO_PUBLIC_API_URL=http://127.0.0.1:8000

Secret backend variable:
GEMINI_API_KEY=<not stored in frontend>
